# Pertemuan 1: Pengertian, Karakteristik, dan Keterbatasan Pemrograman Visual

**Pemateri:** Shata Diyaul Haq  
**Mata Kuliah:** Pemrograman Visual  

---

## 1. Pengertian Visual Programming
**Visual Programming** merupakan pendekatan pemrograman yang memungkinkan proses pengembangan program dilakukan melalui manipulasi elemen-elemen grafis (seperti blok, diagram, dan komponen visual) sebagai representasi dari struktur serta logika program.

---

## 2. Karakteristik Visual Programming
- **Representasi Logika Grafis:** Logika program direpresentasikan melalui blok, diagram, atau elemen grafis yang saling terhubung sesuai dengan alur program.
- **Mekanisme Drag-and-Drop:** Komponen program maupun antarmuka (*interface*) dapat disusun melalui mekanisme seret-dan-lepas (*drag-and-drop*), sehingga proses perancangan menjadi lebih intuitif.
- **Evaluasi Langsung (WYSIWYG / Real-Time):** Perubahan pada rancangan atau struktur program dapat diamati secara langsung, memudahkan proses evaluasi dan pengembangan.

---

## 3. Tujuan dan Manfaat
1. **Mempermudah Pemahaman:** Mempermudah pemahaman konsep dasar logika pemrograman.
2. **Visual & Terstruktur:** Menyajikan alur program secara visual, jelas, dan terstruktur.
3. **Fondasi Pembelajaran:** Mempersiapkan pengguna sebelum beralih mempelajari sintaks kode berbasis teks.
4. **Meminimalkan Kesalahan:** Meminimalkan terjadinya kesalahan (*syntax error*) dalam penulisan kode.

---

## 4. Keterbatasan Visual Programming
- **Fleksibilitas Terbatas:** Sulit untuk menangani kebutuhan spesifik atau algoritma tingkat lanjut yang memerlukan kontrol mendalam.
- **Kurang Efisien untuk Proyek Besar:** Semakin besar ukuran proyek, representasi visual bisa menjadi sangat padat, rumit, dan sulit dipelihara.
- **Ketergantungan pada Platform:** Terikat erat dengan ekosistem dan platform khusus tempat program dibuat.

---

## 5. Contoh Platform Visual Programming
- **Scratch:** Platform berbasis blok yang interaktif, cocok untuk mempelajari logika pemrograman dasar.
- **MIT App Inventor:** Platform visual untuk membangun aplikasi mobile (Android) menggunakan sistem blok.
- **JavaFX:** Kerangka kerja antarmuka grafis (GUI) modern untuk Java.
- **Visual Basic:** Platform klasik Microsoft untuk membangun aplikasi berbasis form dan visual.

---

## 6. Ekosistem Pengembangan Microsoft
- **Visual Basic:** Bahasa pemrograman dari Microsoft yang menyediakan lingkungan pengembangan terintegrasi (IDE) untuk membangun aplikasi dengan pendekatan visual.
- **Visual Studio:** *Integrated Development Environment* (IDE) lengkap dari Microsoft yang digunakan untuk menulis, mengedit, menjalankan, dan melakukan *debugging* aplikasi.
- **.NET:** Platform pengembangan dan kerangka kerja (*framework*) multiplatform serta *open-source* dari Microsoft yang mendukung pengembangan aplikasi menggunakan berbagai bahasa seperti **C#**, **F#**, dan **VB.NET**.
